## 2. 根因：v2 链还是比真实退化温和一档

这是**我上次给你的参数的问题，不是你实现的问题**——你实现得完全正确
（我核对过 dataset_csig_v2_arrow.py，与我方 degradation.py 参数一致）。

但我们后来在自己的训练里也发现了同样的坑，并且已经用数据修正过：

```
              LPIPS(LQ,GT)   DISTS(LQ,GT)
v2 链合成域        0.390          0.228
真实验证域         0.426          0.294     ← DISTS 缺口 0.066，结构性损伤不够重
```

我方教师加了"强档混入"后（下述 §3），全尺度 Score 从 4.082 → **4.132**、
LPIPS 从 0.441 → 0.384——**同一张牌在你那边预计同样有效**。

直觉解释：真实 ISP 的过度降噪比双边+高斯的组合更"狠"，尤其在中频结构上。
v2 链的随机采样有一半落在轻档（q>70、σ<1.2），模型见得太多轻样本，
在真实的重样本上欠恢复。

## 3. 改进项（按优先级）

### P0：混入固定强档（我们已验证 +0.05）

在你的 `csig_degrade_v2()` 外面套一层，50% 概率直接走强档：

```python
def csig_degrade_v2_mix(img_u8, rng, mix=0.5):
    """50% 强档 + 50% 原 v2 链。强档参数为我方对齐真实域标定值。"""
    if rng.random() < mix:
        x = cv2.bilateralFilter(img_u8, d=9, sigmaColor=110, sigmaSpace=110)
        x = cv2.GaussianBlur(x, (9, 9), 1.8)
        buf = io.BytesIO()
        Image.fromarray(x).save(buf, format="JPEG", quality=55)
        buf.seek(0)
        return np.asarray(Image.open(buf).convert("RGB"), dtype=np.uint8).copy()
    return csig_degrade_v2(img_u8, rng)   # 你现有的实现
```

注意：强档是**固定参数**（σ_bilateral=110, σ_gauss=1.8, q=55），不是拉宽随机范围。
拉宽范围会稀释重样本密度，固定强档保证 50% 样本落在真实域强度上。

### P1：自检脚本换成真实域锚点

你现在的 8 图协议自检的是合成域。加一个真实域检查（每 5k 步跑一次）：

```
输入：赛题验证集 case1_lq / case2_lq / case3_lq 的中心 512（真实 LQ，非合成）
通过线：SR 的 PSNR ≥ LQ 基线（23.95），且 LPIPS ≤ 0.43
```

真实 LQ 图我可以打包发你（3 张 512 crop + 对应 GT crop，共 6 个 PNG，<5MB）。
这一步是上一版缺的——你的 checkpoint 选择（last10 按合成域 rank）选不出真实域最优。

### P2（可选）：把 fixed prompt 换成逐图弱语义

现在训练/推理都用同一句固定 prompt。风险：模型把 prompt 当成无信息常量
（等效于无条件），或者更糟——在与 prompt 语义冲突的图上产生方向性伪影。
如果 captioner 开销可接受，训练时 10 词弱语义描述 + 推理同协议更稳。
这条优先级低，P0 见效后再说。
