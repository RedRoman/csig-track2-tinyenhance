# 损失配方整理（供同事训练教师模型）

> 2026-08-28 整理。全文按"教师侧该用什么损失"为主线（这是你重训要用的），
> 附"学生侧蒸馏全配方"供参照（让你理解教师输出会被如何消费）。
> **一句话结论：教师侧只需要保真(Fidelity)三项 + 低频对齐，严禁任何无参考 IQA 项。**
> 我们已用单变量实验证明：IQA 放教师侧必坏（指标反向恶化 + 幻觉），放学生侧配合
> FR 势垒才是安全用法。

---

## 0. 先厘清：教师 loss ≠ 学生 loss

- **学生（TinySR 单步）蒸馏 loss**：学生向教师输出对齐的监督，含我们多条 heuristics。
  这一步我们已托管，不用你管。
- **教师（PixelDiT）训练 loss**：你训练教师本身用的目标函数。**这是这份文档的主体。**
- 两者关系：教师的输出质量上限决定了学生能达到的上限。但**不是你训练教师的 loss
  越复杂学生就越好**——恰恰相反，教师在"保真+干净"上越强，学生越容易蒸馏。

我们 2026-08-27~28 用你的 CSIGv2@240k 做了 4 组换教师单变量实验，这是下面
所有权重建议的实证依据。

## 1. 教师侧：推荐损失配方（可直接复制）

设教师输入 LQ 为 `lq`，参考（干净）图为 `gt`，教师输出为 `s`。全部为 HxWx3 图。

```
L_teacher = λ1·L1(s, gt)
          + λ2·LPIPS(s, gt)
          + λ3·DISTS(s, gt)
          + λ4·L_lowfreq(s, lq)
          + λ5·L_detail_gt_aware(s, gt)     ← 你现有的 detail_losses5x，保留
```

### 各项定义与权重

| 项 | 数学形式 | 推荐权重 | 作用 |
|---|---|---|---|
| L1 | `(s − gt).abs().mean()` | λ1 = **1.0** | 基础像素保真，避免整体变形 |
| LPIPS | 预训练 Alex 感知特征的空间加权 L2 距离 | λ2 = **2.0** | 感知结构对齐，防过度锐化 |
| DISTS | 基于小波/纹理分解的分布距离 | λ3 = **2.0** | 纹理质量匹配，防"像素对但纹理假" |
| L_lowfreq | `L1(avgpool16(s), avgpool16(lq))` × 0.3 | λ4 = **0.3** | 低频锚：SR 不得大幅偏离 LQ 低频。生成模型常把 LQ 保留的结构也"重绘"掉，这一项逼它"**重建**而非**生成**" |
| L_detail_gt_aware | 你的现有实现 | 保持 | GT 感知的高频细节恢复 |

**λ1:λ2:λ3 = 1 : 2 : 2 的依据**：这是学生蒸馏主项里 `w_t_l1 : w_t_lpips : w_t_dists`
的相对比例（见 §2），教师用同样比例训练，学生蒸馏时传导最匹配。不是拍脑袋。

### 严禁加入的项（有实证反例）

| 项 | 如果加入的后果（实测） |
|---|---|
| NIQE 最小化 | teacher_v4 上 λ=1.5：NIQE 4.78→**6.56（反向恶化）**，LPIPS 崩到 0.509 |
| MANIQA/MUSIQ/CLIPIQA 最大化 | 同样崩。MANIQA 冲到 0.967（幻觉线附近），教师开始编造不存在结构 |
| 任何无参考 score 加权 | 统一结论：IQA 是"对抗样本式"目标，平坦区编造微纹理是它的局部最优解，而教师是学生唯一的"干净参考"，脏了就全军覆没 |

为什么教师侧 IQA 必炸而学生侧安全：学生侧有 **FR 势垒**兜底（见 §2 第 5 项），
IQA 往前推的同时 FR 势垒往回拽；教师侧没有这层，IQA 梯度不受约束地走。

### 教师侧可选的"防鳞片"约束

若强档样本上开始出现鱼鳞斑，加一个 GT 感知高频超预算项（我们学生侧在用，
原理：只在 GT 平滑区域限制 SR 高频，GT 本身有细节的区域不限制）：

```
E_sr = box_blur9( (luma(s) − box_blur5(luma(s)))² )
E_gt = box_blur9( (luma(gt) − box_blur5(luma(gt)))² )
mask    = sigmoid( (τ − E_gt) / scale )        # GT 最平滑 35% 区域的软掩码
budget  = 1.35 · E_gt + 2e-4
L_hf    = mean( ReLU(E_sr − budget) · mask )   # 只在平滑区罚超预算
```

这对应我们学生侧 `w_hf_over=1500` 那一项（§2 第 8 项）。

## 2. 学生侧：蒸馏损失全配方（供参照，不用你写）

学生一次前向，多头监督。当前权重为 **v8d 档**（我们最新的完整配方）。

```
L = w_t_l1·L1(s,t) + w_t_lp·LPIPS(s,t) + w_t_ds·DISTS(s,t)          # (1) 蒸馏主项
  + w_l1·L1(s,g)  + w_lp·LPIPS(s,g)  + w_ds·DISTS(s,g)              # (2) GT 保真
  + w_fid·L1(avgpool16(s), avgpool16(lq))                            # (3) 低频对齐
  + w_barrier·[ ReLU(LPIPS(s,g)−cap_lp)² + ReLU(DISTS(s,g)−cap_ds)² ] # (4) FR 势垒
  − w_iqa·R(s)                                                       # (5) 可微 NR 直推
  + w_niqe·NIQE(s)/10                                                # (6) NIQE
  + w_gan·softplus(−D(s | lq))                                       # (7) GAN 蒸馏
  + w_hf_over·L_hf(s,g)                                              # (8) 高频超预算
```

### 各项说明（含实现陷阱，写得具体一点）

**(1) 蒸馏主项** `t` = 教师输出。这是学生和教师之间的核心监督。
权重 `w_t_l1=1.0, w_t_lpips=2.0, w_t_dists=2.0`。

**(2) GT 保真** `g` = 干净参考。防学生退化成"只会模仿教师"——教师也有的
系统性错误，这一项拉住。
权重 `w_l1=0.5, w_lp=1.0, w_ds=1.5`。

**(3) 低频对齐**：`w_fid=1.5`。SR 和 LQ 各下采样 16 倍后 L1。和教师侧 λ4 同理。

**(4) FR 势垒**：`w_barrier=3000, cap_lp=0.26, cap_ds=0.19`。
`ReLU(·)²` 是平滑的平方罚——只有当 LPIPS/DISTS 超过帽值才惩罚，且是二次增长。
这是和学生侧 IQA 项配套的关键：IQA 往前推保真掉，势垒立刻重罚。
**没有它，IQA 项会把学生推成"高 NR 但全是鳞片/模糊"的模型。**

**(5) 可微 NR 直推**（减号 = 最大化，因为这几个分数越高越好）：
`w_iqa=2.0`，每步轮换一个指标（`step % 3`），且各乘 `3.0` 因子：

```
if step % 3 == 0: R = 3.0·w_clipiqa·CLIPIQA(s)
if step % 3 == 1: R = 3.0·w_maniqa·MANIQA(s)
if step % 3 == 2: R = 3.0·w_musiq·MUSIQ(s)/100
```
`w_maniqa=3.0, w_clipiqa=2.0, w_musiq=0.3`。注意 MUSIQ 除以 100 是因为它的
量纲（0-100 分）和 MANIQA/CLIPIQA（0-1）不同。
轮换是显存优化：三个指标全跑一次前向要 30+GB，学生侧承受不了。

**(6) NIQE**：`w_niqe=1.2`，除以 10 是因为 NIQE 量纲和其余不同，需要缩放到
同一数量级。NIQE 是越小越好，所以是**加号**。

**(7) GAN 蒸馏**：`w_gan=0.05, gan_start=300`。
条件 PatchGAN，`D(s | lq)` 输入是 [图, LQ] 拼接。**判别器的"真样本"= 教师输出 `t`**
（不是 GT）：让 D 学教师风格，再推学生逼近。GAN 项权重必须小（0.05 量级），
大了会把学生推向局部纹理编造。判别器 D 单独用 `d_lr=1e-4`：
```
D_loss = softplus(D(s.detach(), lq)).mean() + softplus(−D(t, lq)).mean()
```

**(8) 高频超预算** `w_hf_over=1500`：与教师侧防鳞片项同一函数（§1），
用 GT 的低频能量决定哪些区域平滑，只在平滑区罚学生 SR 超预算的高频。
治鱼鳞斑/过度锐化的最后防线。

### 全部使用中的默认权重汇总（v8d 档）

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| w_t_l1 / w_t_lpips / w_t_dists | 1.0 / 2.0 / 2.0 | w_fid | 1.5 |
| w_l1 / w_lp / w_ds | 0.5 / 1.0 / 1.5 | w_barrier | 3000 |
| w_iqa | 2.0 | lpips_cap / dists_cap | 0.26 / 0.19 |
| w_maniqa | 3.0 | w_gan | 0.05 |
| w_clipiqa | 2.0 | gan_start | 300 |
| w_musiq | 0.3 | d_lr | 1e-4 |
| w_niqe | 1.2 | w_hf_over | 1500 |

**实现陷阱**：DISTS/BARRIER/hf 等处必须在 **fp32** 下计算——autocast fp16 下
DISTS 反传会全 nan（这是实测踩过的坑，代码里已显式 `.float()`）。

## 3. 给同事的落地建议

1. **数据配比**：强档 mix 0.5（固定参数 σ_bilateral=110 / σ_gauss=1.8 / JPEG q55），
   从 240k checkpoint 续训 30~50k 步。教师侧唯一短板是强档保真
   （强档子集 LPIPS 0.240 vs 全集 0.178），这是 v3 重训唯一要解决的问题。
2. **checkpoint 选择**：不要按全合成域 rank 选（会被轻档淹没权重），
   按"强档 200 张锚"选（LPIPS < 0.20、PSNR > 25），再对真实域 case1~3 跑一次
   确认（SR PSNR > 23.95，即 LQ 基线以上）。
3. **发布 checkpoint 用 EMA**（decay 0.999），few-step 推理下更稳。
4. **产出即可**,不用套任何 heuristics——学生侧的蒸馏/GAN/势垒/IQA 会自己吃教师。
   你甚至不需要把教师调得多"好看",只要保真和干净两件事做到位即可。

## 4. 传导率预期（为什么值得做）

我们已实测：教师从 VOSR 换到你的 240k，学生 FR 轴 **+0.060 分**（LPIPS −0.025、
DISTS −0.035、PSNR +1.19dB），只是学生侧 NR 被带崩需要另补。v3 若能再收窄
强档教师 LPIPS（0.240 → 0.18），按传导率估算学生侧再 **+0.01~0.02 分**。
这是当前冲 100 分线（本地全尺度 Score ≥ 4.267）唯一量化过的增量通路。
